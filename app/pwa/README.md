# 老爹．涼糕 PWA 示範 App（Phase 83）

此目錄是一個無第三方執行期依賴的靜態 PWA 外殼，採黑金視覺。它可在支援的瀏覽器中預覽，部署到 HTTPS 網址後可由 iPhone Safari 加入主畫面。

## 預覽
部署後開啟 `/app/pwa/`。目前只在功能分支，尚未部署到正式官網。

## 目前可操作
- 首頁與底部導覽。
- 商品展示入口。
- 示範購物車（僅本頁記憶體狀態，重新整理即清空）。
- 餐車／擺攤、會員、老闆管理入口說明。
- 靜態外殼 Service Worker 快取。

## 明確限制
- 商品與價格不是正式資料，不代表目前可訂購品項。
- 加入購物車只是示範，不會建立訂單。
- 不收集帳號、密碼、地址、電話或付款資料。
- 沒有正式 Auth、Supabase API、付款、物流、推播或管理後台權限串接。
- 老闆入口目前只有安全提示，並非可操作後台。
- 這不是已簽章的 iOS IPA／Android APK，也未上架 App Store／Google Play。

## 安全與部署
- 只快取靜態外殼；不快取 API 或私人資料。
- 不修改正式網站根目錄、正式資料庫或 Supabase 設定。
- 僅可先在此功能分支檢視；部署或合併前須另行核准。

# Phase 64｜老爹 App 顧客端互動原型

## 交付
- 新增 `app/customer-app-preview.html`，單頁響應式顧客端原型。
- 首頁、商品列表、購物車、訂單查詢、餐車／擺攤資訊及會員中心。
- 可加入購物車、調整數量、計算商品小計及輸入訂單編號查看查詢流程示意。
- 黑金品牌視覺，手機優先排版。

## 重要產品規則
- 商品與價格為介面測試用合成資料，不能視為目前實際供應或價格。
- 正式版商品及每日開單資料應由既有資料來源提供。
- 餐車行程可依設定顯示價格；擺攤公開頁不得輸出價格欄位。
- 會員功能須接正式 Auth；訪客訂單查詢須以訂單憑證／驗證流程保護。
- 顧客端不得自行決定價格、運費、付款成功或訂單狀態。

## 限制
- 本階段僅為 HTML/JavaScript 本機互動原型，購物車狀態只存在頁面記憶體。
- 不會建立正式訂單、不呼叫金流、不登入會員、不讀取真實排程或訂單。
- 未修改正式 Supabase、官網、Edge Functions、付款、物流或會員資料。

## 下一階段（Phase 65）
建立顧客端與老闆端共用的正式 API contract 與欄位映射驗收清單，明確區分公開商品／排程資料、個人訂單資料及管理操作；優先定義安全讀取與錯誤處理，不連正式個資、不執行正式寫入。

# Phase 61｜商品、口味、每日開單與排程管理畫面原型

## 交付
- 新增 `app/owner-catalog-preview.html` 響應式管理原型。
- 商品／口味清單：涼糕與蘿蔔糕分類、搜尋、啟用／停售、新增口味示意。
- 每日開單：日期、開單開關、服務地區、備註、當日口味、每日價格與數量。
- 餐車／擺攤排程列表：場次類型、日期、地區地點、口味、發布狀態。
- 價格規則：餐車示意顯示場次價格；擺攤固定顯示「不公開」，不輸出價格。
- 手機與桌面版排版。

## 使用方式
開啟 GitHub Pages 或下載 HTML 後可在瀏覽器檢視互動原型。新增、停售、儲存等操作只更新頁面記憶體或顯示示意訊息，重新整理即還原。

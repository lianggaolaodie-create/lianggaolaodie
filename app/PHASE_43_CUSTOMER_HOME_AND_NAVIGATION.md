# Phase 43｜顧客首頁資訊架構與導覽模型

日期：2026-11-08  
分支：`app/phase-1-planning`  
狀態：框架無關的導覽定義與首頁呈現模型已建立；尚未接入正式原生 UI。

## 1. 顧客端主要導覽

| 導覽 | 用途 |
|---|---|
| 首頁 | 品牌 Banner、公告、服務說明及功能入口 |
| 涼糕專區 | 涼糕商品與口味 |
| 蘿蔔糕專區 | 純米蘿蔔糕與冷凍商品 |
| 餐車行程 | 餐車日期、地區、時間及販售口味 |
| 會員中心 | 會員入口（會員功能仍未實作） |

首頁快捷卡片另外提供：
- 涼糕專區
- 蘿蔔糕專區
- 餐車行程
- 擺攤資訊
- 訂單查詢
- 客服與聯絡

這些是導覽資訊架構，不代表各功能頁面已全部實作。

## 2. 首頁內容區塊

| 區塊 | API 內容鍵 | 規則 |
|---|---|---|
| 品牌主視覺 | `home_banner` | 沒有發布內容時不自行編造 |
| 最新公告 | `announcement` | 僅由已發布內容提供 |
| 服務說明 | `service_rules` | 僅由已發布內容提供 |

首頁同時顯示商品數量、餐車行程數及擺攤行程數摘要。資料未載入、載入中、空資料及錯誤狀態各自保留，不以假資料填補。

## 3. 新增模組

`app/mock-api/customer-navigation.js`：
- `ROUTES`：宣告可見路由及標題。
- `PRIMARY_TABS`：主要導覽順序。
- `HOME_CARDS`：首頁快捷卡片。
- `CONTENT_BLOCKS`：首頁內容區塊與 API key 對照。
- `resolveNavigation(routeId)`：已知路由解析；未知路由安全回首頁。
- `buildHomePresentation(states)`：將 Phase 42 畫面狀態整理為首頁呈現模型。
- `safeMessage(state)`：提供載入、空資料、更新中及錯誤提示。

不包含員工登入、PDA、揀貨或出貨工作站路由，符合本階段暫緩範圍。

## 4. 測試

新增 `app/mock-api/customer-navigation.test.js`，涵蓋：
1. 主要導覽順序。
2. 首頁快捷卡片路由有效性。
3. 正常路由與未知路由回退。
4. Banner／公告／服務說明映射。
5. 缺少首頁內容時不編造內容。
6. 載入中、空資料、更新中及錯誤訊息。
7. API 內容鍵對照。
8. 不包含員工 PDA 等暫緩路由。

執行命令：
```bash
node --test app/mock-api/*.test.js
```

## 5. 尚未完成

- 這是導覽與首頁 view model，不是可點擊的正式 App UI。
- 涼糕／蘿蔔糕專區、購物車、訂單、會員、客服頁仍需各自完成 UI 與功能。
- 會員登入、訪客訂單驗證、結帳與付款尚未接入。
- 尚未進行 iPhone／Android 真機與 App Store／Google Play build。
- 未修改正式 Supabase、Edge Functions、Secrets 或官網，未增加付費服務。

# Phase 46 — 配送方式與結帳資料模型

## 本階段交付
- 涼糕可選「送到府」或「超商冷藏寄放」。
- 蘿蔔糕可選「冷凍店到店」或「冷凍宅配」。
- 明確標記 chilled／frozen 溫層；冷藏寄放不會被描述成冷藏宅配。
- 同一購物車若同時有涼糕與蘿蔔糕，要求分開結帳，避免混淆配送溫層。
- 依配送方式驗證收件人、電話、地址或超商門市資料。
- 建立結帳草稿資料欄位，但運費與應付金額保持 null。
- 所有草稿要求伺服器報價，正式送單保持關閉。
- 購物車快照新增商品分類欄位，讓配送選項依商品類別安全判斷。

## 已知費率處理
舊網站前端曾顯示蘿蔔糕店到店 99／129 元、冷凍宅配 250 元；Phase 34 已將其標示為未核實的前端常數，不能直接當作正式 App 費率。本階段不複製這些金額，也不把涼糕超商冷藏寄放費（舊頁面曾出現的門市費）當作運費。正式費用需由伺服器可信設定／報價 API 回傳。

## 限制
本階段是純 JavaScript 配送選項與欄位驗證模型，未連接物流商、門市查詢、正式報價、付款或訂單 API；不具備正式結帳功能，不是可安裝 App UI。使用合成資料測試，沒有修改正式 Supabase、官網或第三方服務。

# Phase 63｜訂單後台操作介面原型

## 交付內容
- 新增 `app/owner-order-preview.html`，提供手機／桌面響應式訂單管理頁。
- 訂單列表可依訂單編號／顧客、線上／現場來源、商品類別、付款狀態及履約狀態篩選。
- 明細顯示訂單來源、商品、配送／取貨方式、金額、付款狀態、備貨狀態及版本。
- 付款審核只對 proof_submitted 訂單顯示確認／退回操作。
- 備貨流程示範未備貨 → 備貨中 → 已備妥 → 待出貨 → 已出貨 → 已送達。
- 出貨操作有付款確認閘門。
- 已付款訂單先示範退款確認，再允許取消；已出貨／送達訂單不提供取消操作。
- 可重設合成示意資料。

## 資料與安全邊界
- 所有訂單均為 HTML 內的合成測試資料。
- 操作僅更新瀏覽器頁面記憶體；重新整理即還原。
- 未連接 Supabase、正式訂單、付款金流、退款、庫存、物流或會員資料。
- 「標記已退款」只為流程示意，正式版必須由金流退款結果／可信後端狀態確認，不能由前端按鈕直接認定退款成功。

## 後續正式化工作
- 串接已驗證管理員身份與 server-side RBAC。
- 將訂單列表與明細改由最小必要欄位 API 提供。
- 將付款審核、退款、履約更新、取消操作改由交易型 RPC／後端服務執行，支援版本控制、冪等 key 與 audit log。
- 串接實際庫存、出貨單、物流追蹤與 PDA（待設備到位後整合）。

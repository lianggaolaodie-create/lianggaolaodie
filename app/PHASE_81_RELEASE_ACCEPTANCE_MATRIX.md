# Phase 81｜老爹涼糕 App 上線前最終驗收矩陣

## 範圍
本階段建立統一驗收矩陣，涵蓋顧客端、購物車／訂單、付款、會員、管理後台、餐車／擺攤／PDA、iPhone 與網站。

## 驗收群組
| 群組 | 核心檢查 |
|---|---|
| 顧客端與商品 | 商品、口味、價格、停售狀態；餐車價可顯示、擺攤價不得公開 |
| 購物車與訂單 | 金額、唯一訂單編號、重複送單、會員訂單隔離 |
| 付款與匯款證明 | 伺服器付款驗證、私有證明、退款稽核 |
| 會員與通知 | 登入 session、個資隔離、通知收件權限 |
| 老闆後台 | 角色分離、商品菜單、訂單付款出貨庫存稽核 |
| 餐車、擺攤與 PDA | 獨立管理、價格隱藏、掃碼作業資料 |
| 手機、網站與上線 | iPhone 操作、錯誤狀態、備份監控與回復 |

## 判定規則
- 任一 FAIL：NO-GO。
- 尚有 NOT_TESTED：NOT_READY。
- 全部 PASS：READY_FOR_MANUAL_RELEASE_REVIEW，仍需人工簽核，不代表自動部署或已可正式上線。

## 目前狀態
所有檢查預設 NOT_TESTED。這是驗收規格，不代表已對正式 App、付款服務或 production 執行測試。測試需使用 staging 與合成資料。

## 限制
不連接 production、不讀取顧客資料、不建立訂單、不觸發金流、不修改資料庫、不部署 App。
